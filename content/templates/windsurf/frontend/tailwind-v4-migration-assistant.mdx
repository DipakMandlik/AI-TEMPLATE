## Overview

Tailwind v4 moved configuration from a JavaScript file to CSS `@theme` blocks and renamed or
removed a handful of utilities. This prompt handles both halves of the migration: the config
file and the class-usage audit.

## The prompt

```md
Migrate this project from Tailwind v3 to v4:

1. Convert every `theme.extend` entry in `tailwind.config.js` into an equivalent
   `@theme` block in the project's main CSS file, using `--color-*`, `--radius-*`,
   `--spacing-*`, etc. token naming.
2. Search all template/component files for utilities removed or renamed in v4
   (`bg-opacity-*` → `bg-black/50` slash syntax, `flex-shrink-*` → `shrink-*`,
   `flex-grow-*` → `grow-*`) and rewrite every usage found.
3. Confirm `@import "tailwindcss";` replaces the old `@tailwind base/components/utilities`
   directives.
4. Flag any custom v3 JS plugin that has no direct v4 equivalent — these need manual
   review, don't attempt to auto-convert plugin code.

List every file changed and a one-line summary of what changed in it.
```
