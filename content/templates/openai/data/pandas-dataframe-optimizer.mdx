## Overview

Row-wise loops (`iterrows`, `.apply(axis=1)`) and chained indexing are the two most common
sources of both slow and subtly incorrect pandas code. This prompt finds both and rewrites
them to vectorized equivalents that produce the same result faster and without the silent
assignment failures chained indexing can cause.

## The prompt

```md
Review this pandas code for performance and correctness issues:

1. Replace any `.iterrows()`, `.itertuples()`, or `.apply(axis=1)` loop with a
   vectorized equivalent wherever the per-row logic can be expressed as a boolean
   mask, arithmetic, or `.map`/`.replace` operation. If it genuinely can't be
   vectorized (truly stateful across rows), say so explicitly.
2. Replace chained indexing (`df[mask]['col'] = value`) with `.loc[mask, "col"] = value`
   — chained indexing can silently fail to assign or raise `SettingWithCopyWarning`.
3. Flag any large `object`-dtype column that holds a small number of repeated values
   and would benefit from being cast to `category` dtype.
4. Confirm the vectorized rewrite produces the same output as the original for a
   representative sample before considering it done.

Show the rewritten code and explain what changed and why.
```
