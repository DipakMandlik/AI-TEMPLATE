## Overview

Hand-written API docs drift from the actual code the moment a signature changes. This command
generates reference documentation directly from a package's exported TypeScript types and
JSDoc comments, so the docs can be regenerated on demand instead of manually kept in sync.

## The prompt

```md
Generate Markdown API reference documentation for this module's public exports:

1. For every exported function/class/type, include its exact signature as written in
   the source — do not paraphrase or "clean up" the types.
2. Pull the description from its JSDoc comment. If there is no JSDoc comment, say so
   explicitly instead of inventing a description.
3. Include at least one realistic usage example per export, derived from how it's
   actually called elsewhere in this codebase if such a call site exists.
4. Note which parameters are optional and what happens when they're omitted.
5. Group exports by the file they come from, in the order they're exported.

Output one Markdown section per export, ready to paste into docs/api.md.
```
